# Skill: match-facts

**Job:** For each requirement, find the evidence in the fact bank and grade it. Nothing else.
**Reads:** Requirements + Keywords from `01_intake.md`, `_shared/fact-bank.md`.
**Writes:** the Match table in `02_match.md`.

## Steps
1. For every must-have, nice-to-have and key duty, search the fact bank.
2. Grade: **Strong** (direct, verified evidence) · **Partial** (adjacent or approximate) ·
   **Weak** (implied only) · **Missing** (nothing).
3. Cite the fact-bank ID(s) for each grade (e.g. `F-SALES-02`).
4. Only [verified] and [approx] facts count. [confirm] facts are listed but graded as Missing
   until Tobi confirms.
5. Summarize: count of Strong/Partial/Weak/Missing, and the 3 strongest matches.

## Rules
- Never upgrade a grade because the job "sounds like" something Tobi probably did.
