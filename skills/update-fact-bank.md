# Skill: update-fact-bank

**Job:** Add or correct a fact about Tobi. Nothing else.
**Reads/Writes:** `_shared/fact-bank.md`.

## Steps
1. Find the right section. If the fact already exists, edit that line; don't add a near-duplicate.
2. Give new facts the next ID in their section (e.g. `F-STORY-12`).
3. Tag status: **[verified]** Tobi stated it plainly · **[approx]** Tobi gave a rough number; write
   the safe version · **[confirm]** inferred or from an older source, needs Tobi's yes.
4. Record the date and source in a short trailing note ("— Tobi, 11-24-2026").
5. Never store customer names or contact details for customer staff. Describe the customer type.
6. If a correction changes something already on a sent resume, note it in `decisions/`.
