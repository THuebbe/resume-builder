# Skill: recruiter-screen

**Job:** Judge the resume against the posting like a skeptical first-pass recruiter. Nothing else.
**Reads:** `00_posting.md` and the rendered resume text only. Must not read stages 01–03 or the fact bank.
**Writes:** the Recruiter section of `04_review.md`.

## Steps
1. Grade each posting requirement Strong / Partial / Weak / Missing, citing the resume line.
2. Call: advance to phone screen / maybe / reject, with the reason in one sentence.
3. Up to 6 ranked fixes. Rewrite lines only with facts already on the page; anything needing a new
   fact becomes a question for Tobi.
4. Be blunt. No flattery.
