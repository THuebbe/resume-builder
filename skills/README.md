# Skills — one job each

A skill is a single-purpose procedure. Stages call skills; skills never call stages.
Each skill states what it reads, what it writes, and its steps. If a skill starts doing two jobs, split it.

| Skill | Job | Used by stage |
|---|---|---|
| `extract-requirements.md` | Pull must-haves, nice-to-haves, duties, knockouts | 01 |
| `extract-keywords.md` | Pull exact ATS phrases, ranked | 01, 04 |
| `go-no-go.md` | Score the posting against Tobi's targets | 01 |
| `match-facts.md` | Map each requirement to fact-bank evidence | 02 |
| `gap-questions.md` | Turn gaps into questions only Tobi can answer | 02 |
| `select-content.md` | Pick titles, keywords, highlights, bullets, projects | 02 |
| `write-summary.md` | Title bar + professional summary | 03 |
| `write-experience.md` | Job headers, overviews, bullets | 03 |
| `fit-layout.md` | Budget content onto two pages | 03, 05 |
| `ai-tell-check.md` | Find AI-sounding writing | 04 |
| `ats-check.md` | Check machine readability and keyword coverage | 04 |
| `truth-check.md` | Trace every claim to the fact bank | 04 |
| `recruiter-screen.md` | Judge fit like a skeptical recruiter | 04 |
| `render-pages.md` | Fill the template | 05 |
| `export-check.md` | Inspect the exported PDF | 05 |
| `update-fact-bank.md` | Add a new fact from Tobi | anytime |
