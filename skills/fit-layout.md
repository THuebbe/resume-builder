# Skill: fit-layout

**Job:** Make the draft fit the two-page plan. Nothing else.
**Reads:** `03_draft.md`, `_shared/layout.md`. **Writes:** a Fit note in `03_draft.md` (stage 03)
or edits to the render (stage 05).

## Budget (14px Archivo, 704px text width ≈ 100 characters/line)
- Page 1 holds ~44 body lines after header, title bar and section headings.
- Typical split: summary 4–5 lines, expertise 3, highlights 6, job header + overview 3,
  current-job bullets 10–13.
- Page 2: earlier roles, projects, skills, education. Target 65–85% full.

## Steps
1. Count lines per block (characters ÷ 100, rounded up).
2. If page 1 overflows: tighten summary → drop a highlight's second line → shorten bullets →
   last resort, cut the weakest bullet. Never shrink the font.
3. If page 2 is under 60%: add back a project or a skills row from the fact bank. Never filler.
4. Fix single-word last lines by trimming the bullet.
