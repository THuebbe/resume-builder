# Precedence — which rule wins

When two rules conflict, the higher one wins:

1. **Truth.** Nothing goes on the page that Tobi couldn't defend for two minutes in an interview.
   Every claim traces to `fact-bank.md`. Approximate numbers are written conservatively.
2. **A human can read it.** Clean, plain, specific. A hiring manager should get the story in 30 seconds.
3. **ATS can parse it.** See `ats.md`.
4. **Coach style.** Advice from resume coaches (Richard Rose et al.) is followed where it doesn't
   conflict with 1–3. Coaches sell templates; their taste is input, not law.

## Worked examples
- Coach says "copy every keyword from the posting." Truth wins: only keywords Tobi can back up.
  Gaps go to the question list, never onto the page.
- Coach says "super braggy summary." Truth + readability win: brag with numbers, not adjectives.
- Coach uses a 4-column checkmark grid for keywords. ATS wins: one pipe-separated paragraph.
