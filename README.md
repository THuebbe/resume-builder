# resume-builder

A five-stage pipeline that turns a job posting into a tailored, two-page resume for Tobi Huebbe,
built with Interpretable Context Methodology (ICM). Start at [AGENTS.md](AGENTS.md).

Intake → Match → Draft → Blind review → Render.

- Facts live in `_shared/fact-bank.md`, nowhere else.
- Style rules live in `_shared/voice.md`, `layout.md`, `ats.md`.
- Each posting gets its own folder in `applications/`.
