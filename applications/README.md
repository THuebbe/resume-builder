# Applications — one folder per posting

Name: `YYYY-MM-DD-company-role/` (date you started the run).

Inside:
- `00_posting.md` — the posting text, verbatim, with URL and date found
- `01_intake.md` · `02_match.md` · `03_draft.md` · `04_review.md`
- `05_render/` — page sources, final PDF, `notes.md`

When a run is done and no longer active (rejected, closed, hired elsewhere), move it to `_archive/`.
